# LIBERO skill library seed

This directory is a structure-only seed for a validated skill library. It contains no task strategies. Experimental findings are added only after simulator validation.

- `grasp.md` covers acquiring and securing objects.
- `localize.md` covers identifying and localizing relevant entities.
- `transport.md` covers moving held objects between regions.
- `contact.md` covers contact operations involving drawers, knobs, doors, and stoves.

Every curated entry must include its debug-seed pass rate and source task. Entries are added by the curator only.
